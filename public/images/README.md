# Image assets

Place local images here to override default (Unsplash) URLs used by the app.

- **hero/** — Dashboard hero background (e.g. `hero.jpg`)
- **login/** — Login split-panel background (e.g. `login.jpg`)
- **cases/** — Case study card images: `louisiana.jpg`, `wildfire.jpg`, `mangroves.jpg`
- **library/** — Research Library header (e.g. `library.jpg`)
- **sidebar/** — Optional sidebar branding (e.g. `sidebar.jpg`)

The app uses coral-reef and ocean imagery from Unsplash when local files are not present. See `src/data/imageAssets.ts` for URL configuration and credits.
